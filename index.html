A picture for every idea

Each chapter draws its ideas as diagrams before it explains them, from what a single request carries to how an agent decides its next step.

🐍

Notebooks that run with no key

Every notebook replays recorded model responses by default, so it runs in Colab for free and prints what the chapter quotes. A switch calls the live API with your own key.

📚

Linked to its companions

Where a chapter needs statistics, it links to Statistics, Data Science and AI: A Visual Handbook, the first book in the series. Where it needs Python or a library, it links to the guides in Python, Visually.
