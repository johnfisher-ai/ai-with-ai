# The datasets

Every dataset in this folder is written for *Building AI with AI: A Visual Handbook*. They are teaching
datasets. The support tickets, documents, conversations and other records in them are made up so that a
chapter's method has something realistic to work on, and some are dirtied on purpose so a chapter can show
the cleaning as well as the result. None of them is drawn from a real organization or person, and results
computed from them describe nothing outside the book.

Each workbook carries a `Notes` sheet that says the same, and each chapter's dataset card labels its data
as written for the book.

There are no datasets yet. Each one is listed here as the chapter that uses it is published.
